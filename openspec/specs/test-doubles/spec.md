# Test Doubles

## Purpose

Provide deterministic test double classes (`TestEmbedder`, `TestLLM`) in `tests/doubles/` that implement the Embedder and LLM protocols with predictable, content-derived outputs for reliable test assertions.

## Requirements

### Requirement: TestEmbedder produces deterministic pseudo-embeddings

The system SHALL provide a `TestEmbedder` class in `tests/doubles/embedder.py` that implements the `Embedder` protocol. It SHALL produce deterministic 768-dimensional float vectors derived from input content hash. Same input text SHALL always produce the same embedding vector. Output SHALL pass all downstream validation: correct dimension (768), numeric values only (no NaN, no Inf), and vector elements SHALL be in a valid range for FAISS indexing.

#### Scenario: TestEmbedder returns deterministic vectors
- **WHEN** `TestEmbedder.embed_text("hello world")` is called twice
- **THEN** both calls SHALL return identical vectors

#### Scenario: TestEmbedder vectors pass validation
- **WHEN** a vector from `TestEmbedder.embed_text()` is passed to `validate_embedding()`
- **THEN** the result SHALL be `(True, "")`

#### Scenario: TestEmbedder vectors pass normalization
- **WHEN** a vector from `TestEmbedder.embed_text()` is passed to `normalize_embedding()`
- **THEN** the result SHALL be a valid float vector with L2 norm of approximately 1.0

#### Scenario: TestEmbedder supports batch embedding
- **WHEN** `TestEmbedder.embed_texts(["a", "b", "c"])` is called
- **THEN** the result SHALL contain exactly 3 vectors
- **AND** each vector SHALL have dimension 768
- **AND** each vector SHALL be deterministic for its input

### Requirement: TestLLM produces deterministic canned responses

The system SHALL provide a `TestLLM` class in `tests/doubles/llm.py` that produces a deterministic canned response string. The default response SHALL be a generic sentence like "This is a test response generated by the test LLM for testing purposes." The response SHALL be overridable via constructor parameter for tests that need specific output.

#### Scenario: TestLLM returns canned response
- **WHEN** `TestLLM().generate("any prompt")` is called
- **THEN** the result SHALL be the default canned response string

#### Scenario: TestLLM supports custom response
- **WHEN** `TestLLM(response="Custom answer").generate("prompt")` is called
- **THEN** the result SHALL be `"Custom answer"`

### Requirement: Test doubles are importable from any test file

The `tests/doubles/` module SHALL be importable using standard relative or absolute imports from any file under `tests/`. The pytest working directory (project root) SHALL resolve `tests.doubles` correctly.

#### Scenario: Import from integration test
- **WHEN** a test file in `tests/integration/` imports `from tests.doubles.embedder import TestEmbedder`
- **THEN** the import SHALL succeed without errors

#### Scenario: Import from unit test
- **WHEN** a test file in `tests/unit/` imports `from tests.doubles.embedder import TestEmbedder`
- **THEN** the import SHALL succeed without errors
